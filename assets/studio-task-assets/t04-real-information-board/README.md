# T04 대체 시험 패키지

- package ID: `ALT-T04-COSMIC-PULSE-V1`
- 적용 사유: 과제 헌법이 참조한 공식 패키지와 제공처가 프로젝트에 포함되지 않았습니다.
- 승인: 프로젝트 소유자가 2026-09-10에 공개 대체 시험자료 사용을 지시했습니다.
- 범위: 정상 D1-A, 정상 D1-B, 실패 5종, 다음 날짜 복구 D2
- 격리: 모든 합성 기록은 요청별 메모리 저장소에서만 처리하며 SQLite와 Supabase에 기록하지 않습니다.

## 실행 순서

1. D1-A를 저장합니다.
2. 같은 KST 날짜의 D1-B를 저장하고 행이 한 건인지 확인합니다.
3. 선택한 실패 fixture를 adapter에서 발생시키고 마지막 정상값, 시각, 행 수가 보존되는지 확인합니다.
4. 결과가 `stale`이고 실패별 `error_code`와 다음 행동이 표시되는지 확인합니다.
5. `ALT-T04-RECOVER-D2`를 저장하고 `fresh`, `error_code: none`, 행 수 `1 → 2`를 확인합니다.
6. D2를 한 번 더 저장해도 행 수가 2건으로 유지되는지 확인합니다.

계약 필드는 `public-contract.json`, 파일 무결성은 `asset-manifest.json`을 기준으로 합니다.
